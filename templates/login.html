About the forgot-password flow

Checking email configuration…

If you've set SMTP_HOST/SMTP_USER/SMTP_PASSWORD in .env, the 6-digit code is emailed to your real address, and you must enter the matching code before you're allowed to set a new password. Without SMTP configured, there's no way to actually deliver an email, so the code is shown inline instead — clearly labeled as the dev-only fallback, not a substitute for real email. See .env.example for Gmail App Password setup, or run python scripts/test_email.py you@example.com to test your SMTP setup directly, independent of the web app. Just edited .env? Restart the server — environment variables are only read once, at startup.
